# CLS別府 名刺

`CLS別府_名刺.pptx` … 名刺データ本体。スライド1が表面、スライド2が裏面。

- 仕上がりサイズ：91 × 55mm（日本の標準名刺サイズ、塗り足しなし）
- フォント：游ゴシック
- 表面：ロゴ／公式サイト URL／氏名／QR（公式サイト・LINE オープンチャット）
- 裏面：PVMV。PURPOSE・VISION・MISSION・VALUES をロゴの4色で色分け

## 別メンバー分をつくる

表面スライドの「運営チーム」「若林　諒」「WAKABAYASHI RYO」を書き換えるだけでよい。
裏面は共通なので変更不要。

## 印刷に出すとき

塗り足し（3mm）が必要な入稿形式の場合は、97 × 61mm 版を別途用意する必要がある。
